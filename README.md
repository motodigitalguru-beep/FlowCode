# FlowCode 🚀
### Der KI-Agent für smartes VPS-Management

FlowCode ist ein intelligenter SSH-Assistent, der natürliche Sprache in präzise Server-Befehle übersetzt. Speziell entwickelt für n8n-Nutzer und Docker-Admins.

**Features:**
- 🟢 Live Status-Monitoring (Ampel-System)
- 🤖 KI-gesteuerte Befehlsausführung
- 📝 Transparente Aktions-Historie
- 🔒 Sichere SSH-Verschlüsselung
